# Recovery tutorial video policy and production plan

## Purpose

Shopnoltd recovery instructions must be usable as both a video walkthrough and a written checklist. A video is a supporting guide, not permission to skip compatibility checks, backups, or destructive-action confirmations.

## HP Laptop 14s-cf2xxx / Windows 11

### Official video reference

- Title: How to Use the HP Cloud Recovery Tool in Windows 11
- Publisher: verified HP Support channel
- URL: https://www.youtube.com/watch?v=xmtXOU40vxk
- Scope: general HP Cloud Recovery Tool workflow, including preparation, tool setup, USB media creation, and recovery from USB.
- Status: official general reference; not proof that the inspected HP 14s-cf2xxx product number is eligible.

Before using HP Cloud Recovery, collect the exact HP product number and verify eligibility on HP's official support site. The inspected product family alone is not enough to assert compatibility. Preserve the existing E2B USB; choose a separate, expendable USB only after checking its model and capacity.

### Shopnoltd chapter plan

1. Identify the exact HP product number and check HP Cloud Recovery eligibility.
2. Explain the difference between Windows Recovery Environment, a Microsoft Windows installer USB, and HP factory recovery media.
3. Verify backups, recovery keys, and the target disk.
4. Download the HP tool and recovery image only from HP/Microsoft official sources.
5. Verify the image/source and select a separate USB by model and capacity.
6. Explain that media creation and factory recovery can erase the selected USB or target system disk.
7. Boot using the device's supported one-time boot menu and follow the HP recovery flow.
8. Confirm first boot, Windows activation, drivers and Windows Update.
9. Show what to do if the product number is unsupported or the recovery download fails.

## realme C35 RMX3511 / Android 13

### Verified official reference material

- realme troubleshooting and Recovery Mode guidance: https://www.realme.com/global/support/troubleshooting
- realme Bangladesh software update support: https://www.realme.com/bd/support/software-update

No verified official realme C35 RMX3511 recovery video was identified during this review. The catalogue therefore links to realme's written support guidance and does not embed a third-party firmware video as if it were official.

### Shopnoltd chapter plan — recording required

1. Confirm the phone label/model is RMX3511 and record the exact region, current build and battery state.
2. Explain normal restart versus Recovery Mode; do not select Wipe Data or Format Data during a non-destructive walkthrough.
3. Demonstrate Power + Volume Down only as an entry into the documented Recovery Mode.
4. Show how to locate the exact official regional update package only after realme confirms availability for RMX3511 and the current build.
5. Explain backup verification, including app-specific backups, before any update or reset.
6. Demonstrate the documented storage-based update flow only with a compatible official package.
7. Explain that interrupted firmware installation can render the phone unusable and that service-centre repair may be required.
8. Keep factory reset / wipe / format as a separate, explicitly destructive tutorial with a separate confirmation and backup checklist.

Do not record or publish a successful flash demonstration until the exact RMX3511 regional package and procedure have been confirmed by realme and tested on a matching reference device. Do not unlock the bootloader or use third-party firmware packages for this tutorial.

## Video publishing acceptance

- State the exact model, region, OS/build, tutorial date and tested status.
- Show prerequisites, backup warnings, expected screens, failure paths and rollback/service-centre advice.
- Add captions and a text transcript.
- Link to the official publisher source and licence.
- Label general manufacturer videos as general references, not model-specific validation.
- Never use a video thumbnail or title that implies Shopnoltd has tested a recovery path when it has not.
