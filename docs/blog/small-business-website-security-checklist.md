# A Small Business Website Security Checklist

A business website is often the first place customers go to learn about a company, contact its team or make a purchase. It also holds valuable accounts, content and customer information. A few repeatable security practices can reduce common risks without requiring a large IT department.

## Protect every account

Use a unique password for the website administrator, hosting provider, domain registrar, email and any connected service. Store passwords in a reputable password manager rather than sharing them in chat or spreadsheets. Turn on multi-factor authentication wherever it is available, especially for administrator and domain registrar accounts.

Give each team member an individual account. Avoid shared administrator logins, remove access when someone leaves, and use the lowest permission level needed for each task. Review administrator accounts periodically.

## Keep the website and its extensions updated

Apply security updates to the content management system, themes, plugins, server packages and runtime components. Remove extensions and integrations that are no longer used. Before a major update, confirm that a recent backup exists and test the change in a staging environment when possible.

Do not install themes, plugins or scripts from untrusted sources. Check the publisher, maintenance history and permissions before adding a new component.

## Use HTTPS and protect the domain

Make sure every public page uses HTTPS and that the certificate renews automatically. Redirect visitors from HTTP to HTTPS and avoid loading forms, scripts or images from insecure sources.

Protect the domain registrar account with multi-factor authentication and registrar lock where supported. Keep registration and recovery contact details current. Enable renewal reminders or auto-renewal with a valid payment method so the domain does not unexpectedly expire.

## Collect only the information you need

Contact forms should request only information needed to respond. Restrict access to form submissions, avoid sending sensitive information in ordinary email, and publish a clear privacy notice that explains what is collected and why.

Use established payment providers rather than storing card details on the website unless the business has the specialist controls and compliance processes required to do so.

## Back up the site and test restoration

Back up website files, databases and configuration on a schedule that matches how often the site changes. Keep at least one copy separate from the live hosting account, protect backups with encryption and limit who can access them.

A successful backup job is not proof of recoverability. Periodically restore a copy into a separate test environment and check that pages, forms, media and administrator access work.

## Monitor activity and prepare for incidents

Enable security and access logs where available. Monitor failed administrator logins, unexpected account changes, unusual traffic and domain or certificate notifications. Set alerts for backup failures and expiring services.

If a compromise is suspected, preserve relevant logs, restrict affected accounts, rotate credentials from a trusted device, restore only from a known-good backup and contact the hosting provider or a qualified security professional. Do not delete evidence before the cause is understood.

## A simple monthly review

- Confirm administrator accounts and multi-factor authentication.
- Install pending security updates.
- Check domain, DNS and TLS certificate renewal settings.
- Review form destinations and third-party integrations.
- Verify that recent backups completed and that a restore test is scheduled.
- Review alerts and investigate unexpected changes.

## Make security part of normal website maintenance

Website security is an ongoing routine, not a one-time installation. Assign an owner for updates, access reviews and backup checks. Record when each task was completed and what needs follow-up. Small, consistent checks make it easier to spot problems before they interrupt customers or business operations.
