Shopnoltd Offline Device Recovery Guide

Purpose: Keep this guide on a separate USB or another device so the instructions remain available when the target computer has no internet connection.

Prepared as a general safety guide. Always follow the exact device manufacturer's current instructions for the model and region.

Stop before any erase, format, reset, reinstall or firmware flash. These actions can permanently delete data. Verify the backup, device model, target disk and recovery package first. Never guess the disk number or firmware variant.

1. Before recovery

  1. Write down the exact manufacturer, model, hardware revision, region and current OS/build.
  2. Back up documents, photos, browser data, application data and authenticator recovery information where possible.
  3. Verify cloud and app-specific backups separately. A phone backup does not necessarily include every messaging app or local file.
  4. Keep recovery keys, passwords, activation keys and private tokens private. Do not put them in public Git repositories or send them to support chats.
  5. Connect reliable power. For phones, use the manufacturer's recommended battery level and do not interrupt an update.
  6. Identify the removable USB by model and capacity. Disconnect other external disks where practical.
Preserve existing recovery media. Do not format, repartition or overwrite an existing multiboot/E2B USB unless you explicitly intend to erase it and have separately backed up its contents. Use a different blank USB for new media.

2. Windows 10 / Windows 11 PC

  1. If Windows still starts, try Windows Update, Startup Repair and other non-destructive recovery options before reinstalling.
  2. If Windows will not start, use another working PC to obtain installation/recovery media from Microsoft's official download page: Microsoft Software Download.
  3. Microsoft's Media Creation Tool requires a blank USB of at least 8 GB for the supported workflow. It deletes the contents of the selected USB. Check current architecture support on Microsoft's page.
  4. For a compatible ISO, official USB tools include Rufus, Ventoy and balenaEtcher. Their image compatibility differs; follow the OS publisher's recommended tool.
  5. Verify the ISO using the publisher's signature or checksum from the official release page. Do not trust a checksum copied from an unrelated download site.
  6. Use the device's documented one-time boot menu. Confirm UEFI/Legacy mode, Secure Boot and CPU architecture.
  7. Choose Startup Repair or file-rescue options first. A clean install or factory recovery may erase the target system disk.

3. Linux PC

  1. Download the ISO from the official Linux distribution website.
  2. Verify its checksum or signature using the distribution's official instructions.
  3. Use a compatible writer such as Rufus, balenaEtcher or Ventoy. Check that the specific distribution/release is supported.
  4. Confirm the USB device model and capacity before writing. Writing an image normally overwrites the selected USB.
  5. Boot the target PC from USB and choose a live/rescue environment for data backup before installation.
  6. Do not format the internal disk until the backup is checked and the correct target disk is identified.

4. Apple Mac

  • Intel Macs and Apple silicon Macs have different recovery and startup procedures.
  • Use Apple's official macOS Recovery, reinstall and bootable-installer instructions for the exact Mac model and macOS version.
  • Do not assume a generic Windows/Linux USB image can recover a Mac.
  • Back up with the supported Apple backup method before erasing or reinstalling macOS.

Official guidance: Apple Mac support.

5. Android phones and tablets

  • Android devices use manufacturer- and model-specific OTA, recovery or service procedures. A PC bootable USB does not boot Android firmware on a phone.
  • Use only firmware and tools confirmed by the manufacturer for the exact model, region and current build.
  • For supported realme phones, realme documents Recovery Mode using Power + Volume Down after power-off. Storage-based installation is only appropriate when a compatible official package is available.
  • Back up user data and messaging-app data separately. Do not choose Wipe Data, Format Data, factory reset or bootloader unlock during a non-destructive repair attempt.
  • Keep the phone charged and do not force power off during a system update.

Official realme guidance: realme troubleshooting · realme Bangladesh software updates.

6. iPhone and iPad

  • Use Apple's documented recovery/update process with a supported Mac or Windows computer and Finder/Apple Devices as applicable.
  • A generic PC bootable USB is not an iPhone/iPad OS installer.
  • Back up the device before restore. Restore can erase device data.

Official guidance: Apple iPhone support · Apple iPad support.

7. Chromebook / ChromeOS

  • Use the official Chromebook Recovery Utility and the exact Chromebook model/product identifier.
  • Recovery media creation erases the selected USB or SD card.
  • Do not use a recovery image for a similar-looking but different Chromebook model.

Official guidance: Recover your Chromebook.

8. TVs, routers, consoles and embedded devices

  • Use the manufacturer's exact model-specific recovery procedure and firmware source.
  • Do not flash firmware from another model or region.
  • Do not assume USB storage, USB OTG, a service cable or network boot is supported.
  • If the vendor does not publish a safe recovery procedure, contact its authorized service centre.

9. Installing software offline

  1. While online on a trusted working device, download installers only from the software publisher or official platform store.
  2. Check operating system, version, CPU architecture and licence before downloading.
  3. Download the publisher's signature/checksum file where available and verify the installer before copying it to USB.
  4. Copy the installer, verification file and matching offline instructions to a clearly named folder on the USB.
  5. On the offline target, verify the copied file again before running it. Avoid unknown driver packs, cracked software and repackaged installers.
  6. Some installers require an internet connection, activation, licence check or additional packages; an offline copy cannot guarantee installation.

10. When to stop and ask for help

  • The device model, region, storage target or firmware package does not match exactly.
  • The only available instructions require an unverified third-party ROM, bootloader unlock or unknown flashing utility.
  • The backup cannot be verified, or the next step may erase data.
  • The device shows storage failure, repeated I/O errors, battery swelling, overheating or signs of hardware damage.

Shopnoltd: This guide is a safety checklist, not a guarantee of compatibility or successful repair. Follow current official manufacturer instructions and obtain professional service when required.
