# Agent installation

Windows:
ShopnoltdRemoteAgent.exe --enroll <ONE_TIME_TOKEN>

Linux:
shopnoltd-remote-agent enroll <ONE_TIME_TOKEN>

macOS:
shopnoltd-remote-agent enroll <ONE_TIME_TOKEN>

The enrollment token:

- is generated by the Shopnoltd UI
- is single-use
- expires
- binds the resulting device identity to the authenticated Shopnoltd user
- must never be embedded in a public container image
