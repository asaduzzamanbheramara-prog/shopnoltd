# Shopnoltd Remote Device Enrollment

The remote desktop engine is MeshCentral.

Device lifecycle:

1. User opens the Shopnoltd Remote Devices page.
2. User selects "Add device".
3. Shopnoltd creates a pending device record and enrollment token.
4. The device owner installs the MeshCentral agent generated by the
   Shopnoltd/MeshCentral server.
5. The agent maintains an outbound connection to the MeshCentral server.
6. The device becomes visible/online.
7. User selects Connect.
8. Browser opens the MeshCentral remote desktop session.

Supported operating systems through MeshCentral agents:

- Windows
- Linux
- macOS
- other MeshCentral-supported platforms

The agent must be generated by the MeshCentral server for the appropriate
device group. Do not distribute a static hard-coded agent token.
